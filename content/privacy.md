**nibOS collects nothing about you.** It has no accounts, no analytics and no telemetry. The
device only goes online for things you start yourself, and the only thing it ever sends to the
nibOS project is a bug report, when you choose to send one.

## Bug reports

When something goes wrong, nibOS can offer to send a bug report. Nothing is sent unless you
say so.

A report holds the system log from the current start and some basic details about your device
and nibOS version. Before it leaves, nibOS tries to take out things like Wi-Fi details,
passwords and network addresses, but it can't promise to catch everything. Each report is
saved on your card before it is sent, so you can read it first, or skip sending it.

Reports go to the project's own bug tracker. If you'd like one deleted,
[open an issue](https://github.com/abradburne/nibos/issues) with the report's code.

## Other services

Some features use other people's services when you use them, such as updates and PortMaster
(GitHub), RetroAchievements, and network time. Those services see what any web service would,
such as your IP address, and anything you give them, such as a sign-in. They are covered by
their own privacy policies, not this one.

## This website

This site has no tracking, no cookies and no scripts. It is hosted on GitHub Pages and
downloads come from GitHub, so GitHub sees your visit the way any web host would: see
[GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
